ROMI Straight-Line Autonomous Drive
Reflection Worksheet

Instructions:
Below are a series of questions about the autonomous driving project you completed with your ROMI robot. Please choose any 4 questions to answer.
Aim for thoughtful, well-organized responses. Each answer should be about 3–5 sentences long.

(Estimated total time: ~30 minutes)

1. Drivetrain Subsystem Design

  • (a) Why is it useful to create a separate drivetrain subsystem when programming a robot?
  • (b) How does organizing code into subsystems like “drivetrain” make your robot easier to control or expand in the future?

2. Driving Straight: Tuning Error Correction

  • (a) When driving straight based on encoder feedback, why might the robot veer to one side?
  • (b) How does adjusting the “error coefficient” (correction factor) affect the robot’s ability to drive straight?
  • (c) What are the risks if the correction is tuned too weakly or too strongly?

3. Structuring Autonomous Code

  • (a) In your project, the autonomous driving behavior was in robot.py. How could you restructure your code to separate autonomous routines into different files or classes?
  • (b) Why might it be beneficial to organize different autonomous routines separately, especially for competition use?

4. Using wpilib Classes

  • (a) How do classes like DifferentialDrive, and Encoder from wpilib simplify robot programming?
  • (b) Imagine you did not have wpilib — what would writing your robot code look like instead?
  • (c) How does using wpilib encourage a standardized structure for robot code?

Reminders: - Choose any 4 questions total from anywhere on the worksheet. - Please write complete sentences. - Be clear and specific — use examples from your code when possible!
